Use arrow keys to preview mods, N for their links, and Enter or Space to open a focused link. Tab works normally. Press K or use Keyboard controls for help or to disable letter shortcuts.

Keyboard controls

Arrow keys
Navigate the mod grid.
N / Shift + N
Cycle forwards / backwards through the selected mod's links.
Home / End
Jump to the first / last mod in the grid.
Enter / Space
Open the selected link. Hold Ctrl (⌘ on Mac) for a new tab.
Escape
Close quicklink preview and deselect current mod.
M
Mute or unmute sound.
K
Open or close keyboard controls.
